AFRITRUCKS — ZAMBIA RUN (PROTOTYPE 0.1)

Files:
- index.html: the browser game

HOW TO PLAY ON ANDROID
1. Download index.html from the chat.
2. A local file may block some browser features; this game loads Three.js from a free CDN and needs internet.
3. Best free way to run it: publish index.html using GitHub Pages. Create a repository named afritrucks, upload index.html, then Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the GitHub Pages URL in Chrome on your Android phone.
5. Tap START ENGINE. Hold GAS to accelerate, use left/right arrows to steer, BRAKE to slow down, and CAMERA to switch between chase and cabin views.

CONTROLS
- ◀ / ▶: steer
- GAS: accelerate
- BRAKE: slow down
- CAMERA: toggle chase/cabin view
- Keyboard arrows and Space also work on computers.

This is an early prototype, not a complete commercial simulator. It needs an internet connection to load Three.js from cdnjs. Keep the HTML file unchanged when uploading to GitHub Pages.
